## 过程：三轮抽样，全部失败都修了抽取器并重新生成

### 第 1 轮（2188 条，步长 43）：44/50 通过，6 条失败

失败全是系统性抽取错误，不是孤例：

- #16/#17/#19/#20：潍泰 TT 条目“可能原因：X（原表候选，尚非确诊）。”被按括号内逗号
  切开，抽出“尚非确诊）”这种假原因。
- #18：同一原因“转动方向盘时油缸有时动、有时不动”被切成半句“转动方向盘时油缸有时动”。
- #7：约翰迪尔 6E 条目“原表另在故障列写‘降低发动机转速’”是边界说明，被当成原因。

修复：原因值含“（原表候选，尚非确诊）”类限定括号时，整句作一条原因，不再通用切分；
`DROP_SUBSTR` 增加“尚非确诊 / 原表另在故障列写 / 该行故障栏实际写 / 故障栏实际写 /
操作性措辞 / 未明确给出 / 需结合排除栏核对”；引号/括号不成对的碎片直接丢弃。
附带发现：KB-JD-5E-D0-085 整段可能原因只是边界说明（“该行故障栏实际写……属于操作性措辞，
未明确给出损坏原因”），修后该条目无边，计入 no_cause，符合“抽不出留空”。

### 第 2 轮（2065 条，步长 41）：49/50 通过，1 条失败，另发现 2 类潜伏问题

- #10 失败：6M 融合字段“候选涉及车轮跳动、负荷分布、配重、胎压和紧固件松动”里，
  引导词“候选涉及”不在旧解析的标记表里，抽出“候选与相应处理概述：候选涉”这种
  引导头碎片。
- 潜伏问题 1：同类引导词“候选含 / 候选包括”也一样，共 25 条边带引导头碎片
  （如“候选与相应处理概述：候选含冷却液不足漏液”）；另有 ERROR 代码条目
  （KB-KB-M60-20261013-077/080）把代码含义（“ERROR-11为PTO继电器故障提示”）
  和处置句当成了原因。
- 潜伏问题 2：融合字段用“以及”连接候选时切出“……以”碎片
  （“球关节以”“水温传感器以”“燃油不足或脏污以”）。

修复：重写 `parse_fused_cause_field`——先整段去掉“手册表列候选与相应处理概述：”
引导头，只留候选清单区；引导词扩展为表列 / 本表列 / 本页表列 / 候选为 / 候选含 /
候选涉及 / 候选包括 / 本表指向 / 表N-M列（可叠加，如“表6-1列候选包括……”）；
“以及”先换成顿号再切分；“X为候选”去尾；“先区分X和Y”拆成 X、Y 两条候选；
以“先核 / 按本册 / 本表要求 / ERROR-”开头的处置性字段、以及“表N-M将……列为候选”
写法（原因与措施嵌在同一句里切不干净）一律留空，不硬凑。
