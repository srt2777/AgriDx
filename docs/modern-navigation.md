# 新版页面导航与层级

大厅和功能页通过同一个 `NewVersionShell` 渲染，切换路由只替换内容区。主导航顺序固定为：大厅、农机知识、智能诊断、模型工坊、研究依据；桌面为左侧导航，900px及以下为底部固定导航。手机内容区为导航及安全区预留空间，诊断输入区域在导航之上。

大厅不再重复渲染独立页头、四项展区列表和全局页脚；三维建筑选择、装备目录、漫游、全屏及展区详情仍可操作。直接点击主导航打开功能页，三维场景用于探索内容。

页面顶部路径表示当前层级，例如“大厅 / 模型工坊 / 故障检测演示”，每个上级可返回；故障检测仍高亮模型工坊。知识库内部的机型/组件路径属于资料层级，不替代全局导航。

研究依据使用 `/research`，复用现有论文内容，不再自动将新版切回旧版。旧版首页及其研究区块保留；`/hall`旧链接继续进入新版大厅装备目录。命令搜索和状态栏识别研究页与故障检测页。

本轮用户明确授权合并和部署，覆盖此前仅保存PR的限制。先合入精简知识页PR #111，再通过独立分支/PR交付导航修复；只跟进现有开发站自动发布，不操作腾讯服务器或archive目录。

导航回归覆盖五个入口顺序与中英文名称、展区目标、研究页不切换版本、父级高亮、返回路径、共享外框及单一主内容区。最终测试、构建和发布结果以本批PR及开发产物记录为准；未进行浏览器实机验收时明确记录，不以源码检查替代桌面或手机验收。

## 导航收起

3.16.5起，新版共用页头提供“收起导航 / 展开导航”。电脑收起左侧导航后内容区占满原导航列；手机收起底栏后取消底栏占位，保留系统安全区。展开按钮始终留在页头，切换页面与刷新保留偏好；浏览器禁用本地存储时当前会话仍可操作。收起的链接不参与键盘Tab导航，展开后保持原入口顺序和当前页面高亮。

本批同时按用户要求移除共用页头及大厅开场标题下的金色麦穗装饰线，删除对应伪元素、元素和绘制动画；保留院徽、品牌名称与功能控件。

用户同批追加精简首页说明：移除“三维园区·四个展区”、装备陈列入口与示例装备清单、重复统计宣传条、坐标装饰和开场文字，以及共用页头的问号快捷键按钮和“关于这场演示”入口。保留场景内三维模型及点击详情，查找资料与全屏移入底部操作区；旧装备链接仍定位园区，不依赖已删除的清单锚点。
