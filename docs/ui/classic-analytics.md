# 旧版动态数据探索台

2026-11-05验收，批次 classic-analytics-20261104。旧版界面 OV1.2，项目4.0.35；新版界面 NV1.1保持不变。

## 数据和表现形式

在原21路仿真通道上增加8路：行驶速度、燃油消耗率、液压压力、发动机负载、电池电量、电池电流、独立仿真电功率、振动速度有效值。复用原仿真配置、确定性生成器、SSE和浏览器预览适配。均非实车测量、非厂家量程，不设置新告警阈值；电功率是独立仿真序列，不声称与电压电流满足物理守恒。

提供动力作业、油液能耗、电池电驱、温度、定位状态五组预设，设备/文字筛选和1–4路选择。每路保留单位和独立尺度，避免跨单位合轴误读。支持原CSV导入的任意数值/单位数据。

- 折线、面积、样本柱状：按时间定位；断流保持缺口，不补造读数。折线/面积最多约1200显示点，柱状最多80抽样点，原始统计与导出不降采样。
- 数值分布：12个数值区间、统计样本数量，不当作状态时长；常数数据单独一组。
- 仪表：当前读数及仿真量程（导入使用观测范围）；弧长不表示健康度。
- 时间热力：每通道48个时间区间，数值采用实际样本均值、各行独立归一化。空区间不填前值。
- 离散状态：类别计数和最近48样本条带，不插值、不求状态平均。热力中取区间最后实际类别。

## 动态交互

样本到达自动更新；柱形高度、仪表弧线、热力透明度使用短过渡。尊重减少动态效果设置。播放必须人工触发，页面隐藏时暂停。

冻结只复制当前选中样本，后台采集继续。播放从固定快照起点按原始时间推进，支持1×/10×/60×、暂停、拖动时间、回到起点、返回最新数据。通道/来源/时间窗口变化清除快照。快照期间阻止自动版本刷新，离开页面不持久化快照。导出当前可见范围的全部原始样本，包含对象、单位、来源、快照/实时标记；元数据防表格公式注入。

## 方案比较与边界

只增加通道下拉框不能解决表现单一；单屏叠加所有量纲难以阅读。采用分面四路图和预设，重用已有传输与来源协议，不添加图表服务或依赖。LLM、Memory、Planner、Tool Use执行不变，不将趋势或颜色变成故障结论。
