# 旧版农机工作台（2026-11-04）

## 方案比较与选择

本轮参考用户提供的数字孪生平台操作录像，迁移信息架构和操作模式，重新实现界面；未复制录像素材、厂商模型或业务代码。

| 方案 | 优点 | 代价 | 结论 |
| --- | --- | --- | --- |
| 只调整颜色与卡片 | 范围小 | 功能仍分散，采集与响应没有入口 | 不满足任务 |
| 新建独立控制平台 | 页面组织自由 | 旧版仍存在，数据与诊断状态重复 | 维护成本高 |
| 直接升级旧版为统一工作台 | 保留现有知识、诊断、模型和遥测服务，重新组织入口与交互 | 新增工作区页面和浏览器本地数据状态 | 采用 |

## 迁移矩阵

- 分区：总览、农机对象、数据采集、指令与响应、可视化、操作记录；知识、诊断、模型与故障演示接入同一导航。
- 对象：品牌/型号联动、结构目录、部件搜索、适用范围、条目/来源计数、带对象进入资料和诊断。
- 采集：复用已有仿真 SSE、通道目录、最后样本、重连、历史读取和重试；新增 UTF-8 CSV 本地导入、时间/数值映射、原始预览、校验、导出和删除。
- 指令：用户选择任务目的并填写现象，带对象生成诊断草稿，由用户发送；复用已有仿真情景设置和服务端响应，未增加实车指令。
- 可视化：按来源、通道和时间窗口选择；时间比例曲线、悬停/键盘定位样本、原始样本统计、最近30条表格、完整范围导出；采样中断不连线。
- 记录：本浏览器最多100条活动与人工检查记录，可筛选、导出、清除。用户输入不会自动成为已核验结论。
- UI：蓝白工业工作台、分组侧栏、收起/移动抽屉、统一表单与状态、轻量进入/悬停动画、深浅主题、中英切换、键盘焦点与减少动态效果设置。

数字孪生模型绑定、设备写入、实体传感器和真实采集协议不在现有系统能力内，未伪装为已接入。已有模型展示保持其演示性质。业务计数来自知识目录，缺失读数显示空态。

## 数据与执行边界

导入数据仅在当前浏览器 `agridx-workbench-v1` 保存，最多5个数据集、每个5000行、单文件2MB；清理浏览器网站数据会丢失，可先导出。时间须带时区或明确选择Unix单位；重复时间、空值、非有限数字拒绝导入。导出保留来源与单位，文本字段防表格公式注入。存储失败显示提示并保留当前内存数据。

对象选择是知识适用范围，不将仿真通道认作某型号的真实测量。各仿真情景仍遵循原共享服务语义。任务配置不自动调用模型；进入聊天后沿已有LLM/Planner/Tool Use流程与权限执行。新增浏览器记录不是服务端诊断长期记忆，无新增自动执行循环、外部工具或上传接口。

未保存的导入/任务/记录编辑会阻止自动版本刷新；主动离开页面仍应先保存。当前浏览器多标签并行编辑不提供协作合并，应在一个标签编辑本地数据。
