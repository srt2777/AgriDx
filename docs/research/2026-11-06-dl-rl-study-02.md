## 一、深度学习 / 故障诊断方向：S-D Transformer——跨空间学习 + 可变形注意力的农机轴承复合故障诊断（Agriculture 2024）

- 标题：A Novel Transformer Network Based on Cross–Spatial Learning and Deformable Attention for Composite Fault Diagnosis of Agricultural Machinery Bearings
- 作者：文内贡献署名缩写为 M.L.、X.L.、S.L.、C.L.、B.L. 等（作者全名本次未逐字核实）
- 出处：Agriculture 2024, 14, 1397；2024-08-18 发表；DOI：10.3390/agriculture14081397
- 链接：https://www.mdpi.com/2077-0472/14/8/1397
- 方法：监督分类模型；振动信号 → 连续小波变换（CWT，Morlet 小波基）时频图 → 改进 Transformer 分类。

### 核心方法与结论（原文结论；以本次读到的摘要、§1、§3、§4、§5、§6 全文为准）

1. **三段结构（原文结论）**：① 振动信号经 CWT 转为时频图；② 高效特征提取块（EFE）做低层局部特征增强；③ S-D Transformer 做全局特征学习与分类。整体思路是“局部先行、全局随后”：先用卷积把时频图里的故障特征强化出来，再用 Transformer 建长程依赖。
2. **EFE 模块（原文结论，§3.1）**：由 7×7 深度可分离卷积 + 最大池化、两个空洞卷积残差块、高效多尺度空间交叉注意力（EMSA）三部分组成。空洞卷积在不损失分辨率、不增加参数的前提下扩大感受野，获取多尺度上下文；但空洞卷积的卷积核权重会落在不可达位置，造成信息丢失或不均衡，因此配一个注意力模块来补偿。
3. **EMSA 跨空间注意力（原文结论，§3.2）**：把通道重排为 batch 维建立局部跨通道交互，用三条并行路径（两条 1×1 卷积分支、一条 3×3 卷积分支）提取注意力权重；1×1 分支用一维全局平均池化编码通道信息，3×3 分支捕捉多尺度特征表示；再经二维全局平均池化编码全局空间信息、矩阵乘法融合，并用 sigmoid 空间注意力权重聚合。目的是在不做通道降维（避免信息丢失）的前提下建立跨空间的长程依赖。
4. **可变形注意力 D-MSA（原文结论，§3.3.1）**：针对 Swin Transformer 移窗注意力感受野增长不足的问题引入。做法分三步：① 用偏移网络（5×5 深度卷积 + GeLU + 1×1 卷积）从 query 学出可变形偏移量，用 s·tanh 限制偏移幅度；② 参考点加偏移后双线性插值采样变形后的特征图；③ 带相对位置偏置做注意力计算。与 ViT（全局注意、感受野最大但计算贵、局部特征弱）和 Swin（窗口内注意）相比，DA 只关注图像中一小块重要区域，计算量小且保持性能。
5. **S-D Attention 编码器（原文结论，§3.3.2）**：四阶段层级结构，每阶段（除第一阶段外）先经 patch merging 下采样、再堆叠编码器块。Stage 1–2 用 Swin 的 W-MSA / SW-MSA；Stage 3–4 在 SW-MSA 后紧跟 D-MSA，两者融合为 Shift–Deformable Attention（SDA）。SW-MSA 靠移窗实现窗口间信息交换、捕捉全局信息；D-MSA 动态调整注意位置、捕捉关键局部细节；两者融合既缩小了注意区域（降计算与显存），又保持了特征表达能力。
6. **自采数据集 ScD（原文结论，§4.1.1）**：自建轴承试验台采集，伺服电机 + 联轴器 + 两个加速度传感器（水平/垂直，灵敏度 100 mV/g，采样频率 20 kHz，负载为 0）+ 信号采集器；被测轴承 HRB-7203AC；电火花加工（EDM）在内圈、外圈、保持架引入故障，孔/槽宽 2 mm、深 0.5 mm（外圈单点槽深 1 mm）；共 9 种故障（4 种单故障 + 5 种复合故障）+ 正常状态；转速分 1600/2000/2400 rpm 三档（不同故障类别对应不同转速，见原文）；每类信号滑窗切片（窗长 1024）后经 CWT 生成 1000 张 224×224 时频图，训练/验证/测试按 600:200:200 划分。
7. **主实验结果（原文结论，§5.1）**：ScD 上验证准确率 94.3%、F1 94.27%，为对比的 6 个模型（AlexNet、Vgg、InceptionV3、ViT、Swin Transformer 及本文方法）中最高，且计算复杂度与参数量保持在较低水平；比 Swin 高 2% 以上、参数量更少。CNN 类方法难以建模长程依赖，准确率与参数量难以兼顾；ViT 因局部特征提取不足，准确率略低于 CNN；Swin 强化局部特征后明显提升。最难类别为标签 4（IRP_ORP_H，内圈钻孔 + 外圈钻孔 + 保持架复合故障），本文方法达 91%，其他方法最高仅 79%；除 ViT 与本文方法外，其他模型识别正常类别（标签 5）的准确率也不高。
8. **消融实验（原文结论，§5.2）**：基础 Transformer 约 86%（60 epoch 后才稳定）；只加 SDT 模块 +3% 且 FLOPs 与参数量下降；再加 EFE 达 92.5%（初期波动但提升快）；再加 EMSA 后最终 94.3%，且 EMSA 只增加 0.04G FLOPs 与 0.002M 参数；EFE + EMSA 合计只增加 0.17G FLOPs 与 0.296M 参数，却带来 4.6% 的准确率提升；完整模型约 40 epoch 后稳定，收敛最快。
9. **泛化实验（原文结论，§5.3）**：在 CWRU、PU、XJTU-SY 三个公开轴承数据集上准确率与 F1 均很高；CWRU 与 XJTU-SY 上表现最好，PU 上略低但仍很高；PU 上 23% 的 K101 被误判为 KA04（两类特征重叠、分离不佳）；XJTU-SY 上最低类别仍有 98%–99%。t-SNE 可视化显示本文方法各类簇分离最清晰、簇内最紧凑。
10. **作者自认的局限（原文结论，§6）**：训练用时频图样本量充足且每类样本数一致；小样本或类别不均衡条件下的网络性能尚未验证，是未来工作。

### 与 AgriDx Agent 的直接相关（推断为主，逐条标注）

- **复合故障 ↔ 多症状并发（推断）**：AgriDx 用户一次常报多个症状（如“异响 + 冒黑烟 + 动力下降”），对应本文的复合故障——最难、也最容易被单故障模型误判。本文最难复合类别 91% vs 其他方法 79% 的差距提示：AgriDx 评测应单独设“多症状并发”用例组并单独报数，不能只报总体准确率；知识库案例也应优先补“复合故障”条目（目前 17 个合成案例中复合类覆盖情况未核实）。
- **局部 + 全局 ↔ 关键症状词 + 整段上下文（推断）**：EFE/EMSA 先抓局部关键特征、S-D 注意力再建全局依赖，这与 AgriDx 诊断的阅读顺序同构——先定位关键症状词（异响部位、烟色、温度），再结合整段描述（机型、作业条件、发生过程）做判断。提示词可显式要求模型先列出“关键症状点”再综合判断，相当于把 EFE 的“局部先行”写进推理步骤。
- **可变形注意力的“只看重要小区域”（推断）**：DA 不扫全图、只聚焦关键区域，对应 AgriDx 检索与阅读的纪律——检索返回的条目只取与症状直接相关的片段作为证据，而不是把整条知识条目都塞进上下文；证据越聚焦，误判越少。这与之前笔记“中间变量显式共享”（把已确认的症状、条目 ID 传给下一步）是同一方向。
- **混淆矩阵按类别拆分（推断）**：本文用混淆矩阵与 t-SNE 找出最难类别（复合故障、正常类），AgriDx 评测也应按故障类型拆分准确率，找出“最难诊断的故障类型”和“最容易把正常判成故障的类型”，而不是只看一个总准确率；这与 Sensors 2026 笔记“误报与漏检分开报”互相印证。
- **小样本局限正中 AgriDx 现状（推断）**：作者承认小样本/不均衡未验证；AgriDx 知识库同样小样本（17 案例、T70 仅 2 条），且类别分布不均。本文的经验是“结构改进（注意力）可以在样本充足时提效，但不能替代样本”——AgriDx 补知识库案例仍是比调提示词更根本的工作；同时评测时应标注“小样本类别”的结果不可信。
- **要警惕的地方（推断）**：94.3% 是受控试验台数据（单一轴承型号、无负载、固定转速档）上的结果，与田间真实拖拉机工况差距大，不可直接当作 AgriDx 可达到的指标；ScD 数据集未公开（自采），结果未被第三方复现；本文是纯信号分类模型，不涉及对话、规划与工具调用，借鉴点在“评测拆分与证据聚焦”的方法论，不在模型本身。

### 对 AgriDx 最直接的一条借鉴（推断）

评测按故障类型拆分报数，单设“多症状并发（复合故障）”用例组；诊断推理先列关键症状点再综合判断；知识库补复合故障案例——小样本下结构改进代替不了样本。

## 二、强化学习 / 智能体多步决策方向：MS-GRPO——面向序贯决策的多步组相对策略优化

- 标题：Reinforced Language Models for Sequential Decision Making（MS-GRPO: Multi-Step Group-Relative Policy Optimization）
- 作者：Jim Dilkes、Vahid Yazdanpanah、Sebastian Stein（University of Southampton）
- 出处：arXiv:2508.10839v1 [cs.CL]，2025-08-14 提交
- 链接：https://arxiv.org/abs/2508.10839（HTML 全文：https://arxiv.org/html/2508.10839v1）
- 代码：本次未核实是否有公开代码仓库。

### 核心方法（原文结论；以本次读到的 arXiv HTML 全文摘要、§1–§5、讨论与结论为准）

1. **问题定位（原文结论，§1）**：现有 LLM 后训练方法（RLVR、RLHF）面向单轮交互、即时反馈，无法处理多步智能体任务中的信用分配（credit assignment）；LLM 本身也不擅长低层动作选择与规划，有效决策往往依赖大模型 + 昂贵的长推理链（例：GPT-4o 做真实数字任务每任务约 $0.70 且成功率不足 50%）。目标是让小模型通过针对性后训练获得序贯决策能力，而不是靠扩大模型规模。
2. **形式框架 TMSG + LAP（原文结论，§2）**：文本中介随机博弈（Text-Mediated Stochastic Game, TMSG）把环境建模为所有交互都经文本进行的随机博弈（观察空间即全体文本串）；语言智能体策略（Language Agent Policy, LAP）把智能体策略参数化为四件套：LLM 本体（θ）、生成配置 G（温度、top-k 等）、提示模板 T（把观察填入模板生成完整提示）、动作解析函数 ψ（把模型输出文本解析为合法动作，解析失败记为 ⊥ 并执行预设恢复策略，如无动作或随机动作）。每步流程：模板拼提示 → 模型采样文本补全 → 解析出动作 → 环境转移并返回奖励与新观察。
3. **MS-GRPO 算法（原文结论，§3）**：把 GRPO 从单轮推广到多步：对同一初始观察采样 G 个 episode，把每个 episode 的**全部累计奖励**归因到该 episode 的每一步（Monte Carlo 信用分配），组内归一化得到优势值 A_j；token 级裁剪目标 + KL 惩罚（对参考模型）；只优化 LLM 参数 θ，不优化模板与解析器；优化每步时只用当前状态作上下文；不用 critic（相对 PPO 省显存、可训更大模型或更长上下文）。复合奖励 C_j = 累计环境奖励 + 任务相关的 shaping 奖励 Φ。
4. **绝对优势加权采样 AAW（原文结论，§3）**：受优先经验回放启发，先算全部 G 个 episode 的组相对优势，再按 |优势| 的 softmax 采样 G' < G 个 episode 用于训练，温度 T_ep 控制加权强度（越小越集中于极端优势 episode）。直觉：最成功与最失败的 episode 提供的信息量最大。实验：G=100、G'=25 时比不采样基线（G=100、G'=100）省 3.5 倍训练时间，最终奖励相当（-0.72 vs -0.86）；固定采样数时生成更多 episode 再采样效果更好。
5. **奖励设计（原文结论，§4）**：总奖励 = 环境奖励（含无效动作 -0.5 惩罚）+ 格式惩罚 Φ：长度惩罚（180–200 token 间线性罚至 -0.5）、结构惩罚（每缺失/多余/错误嵌套一个 XML 标签 -0.5）、结尾多余文本惩罚（最终 `</action>` 标签后还有文本 -0.5）。
6. **实验结果（原文结论，§4）**：后训练模型为 Qwen2.5-3B-Instruct，在 Snake 与 Frozen Lake 两个 2D 网格环境上训练（各 700 步、8 次独立运行、每步 50 个 episode 评估）。Frozen Lake 上后训练 3B 模型达 0.57±0.12，超过 72B 基线 0.38±0.48，且只用 200 token 上限（基线 4096 token）；Snake 上均值 -1.49、最佳单次 0.45，方差极大（训练对初始条件与早期探索敏感，部分收敛、部分停滞）。DQN 基线在 Snake 上达 4.58±2.47，远超最好的 MS-GRPO 智能体（0.45）——窄任务上专用模型仍远胜通用 LLM 智能体。
7. **泛化喜忧参半（原文结论，§4）**：Snake 训练的最优智能体零样本迁移到未见过的 FrozenLake-Slippery 上得 0.32，超过 DQN 的 0.17，显示对新动态的适应力；但同一智能体在 Snake-Poison（苹果变有毒）上比后训练前的基底模型更差——学到的“找苹果”行为无法被提示词中“苹果有毒”的语义覆盖，即强化某一技能可能压制模型对关键语义细节的响应。
8. **作者自认的局限（原文结论，讨论节）**：① 训练不一致，源于探索不足——LAP 智能体的探索是 token 空间探索的间接结果，不像传统 RL 可直接用 ε-greedy 探索状态-动作空间；建议动态调采样温度、换提示模板促进探索；② Monte Carlo 信用分配不精确，可能稀释真正有效行为的学习信号；③ AAW 的改进幅度不大，需在更多环境上验证；④ 绝对性能上仍远不及专用模型，LLM 智能体的价值在灵活性而非单任务最优。

### 与 AgriDx Agent 的直接相关（推断为主，逐条标注）

- **信用分配 → 轨迹级归因（推断）**：AgriDx 走 DeepSeek API 路线、无法做权重 RL 训练（与此前笔记结论一致），但 MS-GRPO 的信用分配思想可直接用于离线轨迹评分：一条诊断轨迹最终对错，不应只记一个总分，而应把结果归因到每一步——哪步检索关键词错了、哪步该追问却没追问、哪步在无证据时给了确定结论。Tool-R1 笔记的三段式奖励（答案 + 调用合法 + 执行成功）是“分段记分”，MS-GRPO 补上的是“分步归因”，两者合起来才是完整的离线轨迹 rubric。
- **AAW → 优先复盘极端轨迹（推断）**：AgriDx 的优质轨迹池（PR #213 的 exemplar 方向）不应均匀采样，而应优先纳入“极端成败”轨迹——一次就答对的漂亮轨迹和错得离谱的轨迹最值得复盘与当 few-shot 示例；全对的平庸轨迹信息量低。这与 Tool-R1 的“中等难度过滤”互补：难度过滤决定“哪些用例值得测”，AAW 决定“哪些轨迹值得学”。
- **毒苹果教训 → 硬约束不可被示例覆盖（推断）**：MS-GRPO 的毒苹果失败是最值得 AgriDx 警惕的一点——强化“给确定答案”的行为模式后，模型会无视提示词里的关键语义约束。对应 AgriDx：“无工具证据不得给确定性结论”必须做成硬约束（解析/校验层拦截，如答案含确定性结论但无引用条目 ID 则降级或追问），而不能只依赖提示词或 few-shot 示例，因为示例本身可能教会模型“自信作答”。
- **LAP 四件套 → Planner 的可拆结构（推断）**：LAP 把智能体拆成 LLM / 生成配置 / 提示模板 / 动作解析 + 恢复策略四部分，AgriDx 的 Planner 也可以这样拆开调：提示词模板、工具调用解析与校验、解析失败的恢复策略（重试、换关键词重检索、追问用户）各自独立，而不是把所有逻辑都塞进一个大提示词。尤其“解析失败 → 预设恢复策略”值得抄：AgriDx 工具调用解析失败时应有明确的 fallback，而不是让模型自由发挥。
- **格式惩罚 → 调用格式单独记分（推断）**：MS-GRPO 把格式错误（长度、结构、多余文本）单独计入奖励，与 Tool-R1 的 R_parse / R_exec 呼应。AgriDx 离线评分也应把“工具调用格式是否合法”单独列一项，不与答案正确性混在一起，否则分不清是推理错还是格式错。
- **DQN 教训 → 窄任务上专用小模型更优（推断）**：Snake 上 DQN 4.58 vs LLM 智能体 0.45，说明窄而明确的子任务上专用模型远胜通用大模型。AgriDx 的某些子任务（如“症状文字 → 故障类别”的分类、“是否需要追问”的二分类）未来可考虑用专用小模型或规则分类器，而不是全靠大模型一轮生成；但这需要训练数据与部署成本，不在当前提示词层工作的范围内。
- **高方差警告（推断）**：Snake 训练 8 次运行均值与最佳差距巨大，提醒 AgriDx 的评测不能只跑一次报一个数——同一批用例多次运行、报均值与方差，否则一次好结果可能是运气。
- **要警惕的地方（推断）**：Snake / Frozen Lake 是 4 动作 2D 网格玩具环境，与农机诊断场景差距极大，0.57、50% 等数字不可迁移到 AgriDx；Monte Carlo 信用分配本身就是作者承认的不精确方案，AgriDx 借鉴“分步归因”时应做成人工可审的规则归因，而非照搬算法；代码仓库本次未核实是否公开。

### 对 AgriDx 最直接的一条借鉴（推断）

离线轨迹评分从“整条轨迹一个总分”升级为“分步归因 + 分段记分”（答案 / 调用格式 / 执行成功 / 每步决策），轨迹池优先复用极端成败案例；“无证据不得给确定结论”做成校验层硬约束，不能只靠提示词。

## 本次两篇的共同点（推断）

- 两篇都在讲“归因要落到点上”：S-D Transformer 用可变形注意力把故障定位到时频图里的关键小区域；MS-GRPO 把 episode 奖励归因到每一步动作。AgriDx 的评测与诊断也应如此——答案要能指到具体证据条目，轨迹评分要能指到具体步骤，而不是只有一个笼统的总分。
- 两篇都反对“只看一个总分”：S-D 用混淆矩阵、消融、t-SNE 拆开看哪类故障最难、哪个模块真有效；MS-GRPO 的 Snake 实验显示均值会掩盖方差（均值 -1.49、最佳 0.45），且总分提升可能来自“强化了错误的行为模式”（毒苹果）。AgriDx 的任何“准确率提高了”都应拆开报、多次运行报方差，并检查提升是否以牺牲语义约束为代价。
- 两篇的落点都不需要权重训练、不需要生产改动：S-D 的借鉴在评测拆分、证据聚焦与知识库补案例；MS-GRPO 的借鉴在离线轨迹评分的归因结构与校验层硬约束。两者与此前五次笔记的结论互相印证——结构先于模型、证据先于结论、评测先于优化。
