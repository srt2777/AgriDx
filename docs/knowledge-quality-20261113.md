## 复现与恢复

`node --import tsx scripts/build-literature-index.ts --quality-filter` 对当前书目执行筛查并重建全部分片、词项和哈希。初次清理报告与逐条排除理由保存在 `data/literature/quality-audit.json`、`quality-exclusions.jsonl.gz`；从清理前提交恢复数据后可复现首次清理。直接重跑只会扫描当前保留子集，审计报告会记录当次输入。

`node --import tsx scripts/audit-knowledge-content.ts` 检查全部本地归档、学习及研究摘录。`tests/literature.test.ts` 对每条当前书目执行质量门槛检查，未筛选的重新采集结果不能通过测试。历史采集证据不改写；通过 Git 恢复旧数据前需重新评审其用途，不恢复旧的混合数量宣传。

本次没有建立网络抓取循环，不宣称 DOI 可访问、全文已读或实车性能已验证。
