分支：`feat/agent-tooluse`；初始基线：`2f206e9`；同步主线 `289877e`（界面整理 4.0.7）。本批协调版本：4.0.8（分支状态，不能据此推断 main 或开发站已更新）。本文件覆盖前几轮检查点的“完全隔离、尚未接入”描述；历史提交保留。

## 本批实际交付

已接通一条默认关闭、无需外部密钥的 Node 本地资料定位工作流：表单 → 严格输入与同源校验 → 规则规划 → 有界只读工具循环 → BM25/关键词融合或完整快照故障码查询 → 来源与机型复核 → 安全提示、原文引用和最多三个追问。浏览器通过独立可滚动弹窗查看工具状态、展开引用与页码、停止、重试、导出状态记录。当前目标是可靠的资料定位，不生成未经证据支持的参数或维修结论。

- 5 项真实策略抽查通过：缺机型追问、危险请求拒绝、指令覆盖拒绝、不存在代码不猜含义、本机资料引用。
