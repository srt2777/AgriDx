# 诊断证据协调与多轮交互

本轮基于既有索引、快照、检索缓存、三模式路由和设备记忆改造，不重建诊断系统，不调整维修知识事实，不运行数据清洗任务或新增模型调用。交付只提交独立 PR，等待审查，不合并、不部署。

## 审查发现

基线 `fcf7b37` 的 `东方红 LF1504 水温过高` 检索为 0，但 LF1504 来源已有 188 条归档。症状别名要求在标题或正文整词命中，加上指定机型后排除通识，导致现有冷却安全资料未被召回。此现象不是车型识别失败，也不证明不存在该机手册。现有资料没有直接覆盖该故障的完整原因、检查和维修流程。

本地答复以服务状态和摘录为主；前端又优先显示本地短摘要并丢弃来源、协调和追踪元数据。外部生成原先直接返回，来源和危险操作要求仅写在 prompt 中，没有独立输出检查。

开发中远端并行合入 PR #82（`fc98a25`，3.11.0），本分支已以 fast-forward 保留版本历史页面及其构建能力。版本协调单独按用户授权处理，不倒退覆盖主线版本。

## 最小改造边界

检索使用一次已经验证的内存快照，不在请求内重新读取索引或跑后台清洗。命中仍保留真实词法分数，并明确未经概率校准。评分只是相关性信号；来源索引绑定、适用性、文献审核、内容覆盖及风险分别评估，不能被高分替代。

| 层级 | 依据与限制 |
| --- | --- |
| exact | 明确车型及配置适用；仍须检查内容是否真正覆盖当前问题 |
| series | 来源明确覆盖的系列或多个型号；不从 LF 等前缀推断可互换 |
| component | 复用通用框架与层级组件关联，只补充适用范围兼容的本机资料；关联只表示参考相关，不能证明故障原因 |
| general | 通用原理或通识；标明无本机手册证明，不提供本机参数或跨车型维修步骤 |

排放、驱动配置、驾驶室配置、发动机和故障码的明确冲突仍是硬排除条件。核验失败资料不进入生成上下文。组件与通识层不得因为高相关分或文献核验通过，自动升级为直接维修依据。

`retrievalOutcome` 将资料覆盖与命中区分：`no_manual` 表示当前设备无匹配的已登记手册范围；`no_results` 表示检索没有可用结果；`insufficient_evidence` 表示有参考但不足以回答当前问题；`sufficient` 仍只表示资料条件满足，不表示车辆确诊。缺少设备身份时不得由空命中断言没有手册。

## 三模式

| 模式 | 行为 |
| --- | --- |
| 自动协调 | 本地优先；充分且低风险时直接基于本地回答；不足时遵守服务端配置决定是否一次生成 |
| 仅知识库 | 所有路径零外部调用；没有证据时说明缺口，只收集现场信息并给必要安全提醒 |
| AI 辅助 | 本地资料仍是优先事实依据；生成补充单独标为通用参考或 AI 推断，不冒充核验资料 |

原有 `ALLOW_EXTERNAL_AI`、`DIAGNOSIS_MODE` 和供应商配置继续生效。服务端禁用外部 AI 优先于浏览器选择。无密钥、配置无效、超时、主备供应商失败均保留本地退路；安全路径、身份冲突和未知操作风险不因模式切换而放行。

## 回答、来源与安全

`DiagnosticReply` 由服务端构建：简要理解、资料支持等级、带证据编号的原因候选、安全优先建议、最多两个追问、来源适用说明。AI 补充独立放在 `aiSupplement`，不自动转写为本地事实。

`knowledgeSources` 传递原始来源编号、知识编号、页码、版本、适用限制、审核状态和检索层级。`usage` 区分本地建议依据、提供给模型的参考和候选参考。提供给模型不代表模型的每句陈述都已由该来源证明。文献核验不得写成厂家验证或实车维修验证。

外部生成完成后执行确定性来源和安全检查；只接受本次实际发送的证据引用。无效引用、缺乏依据的专用参数或危险正向操作被拒绝后，回退本地计划，不再额外调用模型。禁止操作的安全提醒不能因为包含风险词而简单删去。

该检查是保守规则门，不能证明自由文本的完整语义蕴含，也不能替代专业人员判断。没有经过真实外部供应商运行的测试，不宣称线上模型安全率或诊断准确率。

## 交互与记忆

主回答展示故障分析、下一步建议、关键追问及简短来源说明；模型、路由原因、计分、命中数量和时延集中在可展开的“诊断依据与技术详情”。旧消息无结构化元数据时继续显示原文，不补造历史来源。

沿用设备档案和已有服务端消息 JSON 保存新元数据，无需数据库迁移。车型修改和换设备继续遵守现有档案保存与新建诊断限制，不混用其他设备检查进度。用户报告的已完成检查用于追问选择，但不当作已核验维修事实。

故障码和发动机信息作为本次诊断补充。附件仅支持受限 UTF-8 文本 `txt/log/csv/json`，文件最大 16 KB，描述和附件合计最多 2000 字符；发送时以“用户提供、未经核验”的文本进入本轮消息，不支持图片识别。文件在发送前留在浏览器，可移除。

## LF1504 水温过高的验收边界

应找回有真实组件关联的 LF1504 冷却安全参考，保留出处和适用条件，并明确原因证据不足。现有 `KB2000-20261015-YTOLF1504-010` 可支持热机冷却液盖安全禁令，但不能据此推出水泵或节温器损坏，也不能编造温度阈值、容量和维修步骤。`KB-YTO-LF1504-004` 的停机冷却资料也不能冒充完整水温故障诊断。

回归需经过真实 HTTP 请求、知识快照、检索、协调、答复和记忆恢复，并检查桌面及手机端阅读、追问按钮、模式选择和技术详情。外部供应商错误使用可控测试替身，明确与真实线上模型验证区分。
