# 已有知识库图谱工作台

入口：`/#/knowledge?view=graph`。从统一知识目录选择“知识图谱”。

图谱由现有 `/api/knowledge/catalog` 的品牌、型号/系列、组件、零件层级生成，不新建第二份事实正文、不调用外部模型、不导入外部资料。左侧选择品牌、机型和系统，中间图谱点击或键盘展开零件，右侧显示原有知识卡、来源、页码及核验状态，可带机型进入诊断。没有零件或条目时保留缺口；未定位到零件的条目仍留在组件层级。

实线仅表示已经整理的目录关联，不表示因果、故障确诊、实车验证或完整覆盖。系列与待确认机型不等于具体型号；通识资料继续在独立浏览入口显示，不通过图谱自动提升证据等级。计数来自目录，不将跨组件引用相加当作新增条目。

桌面采用目录、图谱、证据工作区；中等宽度证据下移；手机提供目录/图谱/证据面板切换。SVG节点支持点击、Enter和空格，资料读取有加载、失败重试与空状态。借鉴持久化知识与来源分离思路，继续使用本项目归档及人工维护的hierarchy.json作为事实和关系来源；未复制外部LLM Wiki代码，无新增运行依赖。
