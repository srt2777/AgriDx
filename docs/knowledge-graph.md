# 已有知识库图谱工作台

入口：`/#/knowledge?view=graph`。从统一知识目录选择“知识图谱”。

图谱由现有 `/api/knowledge/catalog` 的品牌、型号/系列、组件、零件层级生成，不新建第二份事实正文、不调用外部模型、不导入外部资料。默认收拢为一颗知识球。点击或放大后，整球平滑分成多个品牌球；进入品牌球展开该品牌的机型球，再逐层进入组件球、零部件球。球内微光表示下一层目录，层级面包屑或缩小可返回。点击零部件聚焦相应证据。侧栏展示原有知识卡、来源、页码及核验状态，可进入完整机型目录及诊断。没有零件或条目时保留缺口；未定位到零件的条目仍留在组件层级。

实线仅表示已经整理的目录关联，不表示因果、故障确诊、实车验证或完整覆盖。系列与待确认机型不等于具体型号；通识资料继续在独立浏览入口显示，不通过图谱自动提升证据等级。计数来自目录，不将跨组件引用相加当作新增条目。

球体支持拖拽惯性旋转、滚轮/按钮缩放、自动旋转、鼠标吸引/排斥力场、搜索定位和全景复位；球体聚焦时方向键旋转、Esc关闭详情，节点使用原生按钮支持Enter和空格。手机端证据面板放在球体下方，减少动态偏好关闭自动旋转、惯性与鼠标力场。资料读取有加载、失败重试与空状态。借鉴持久化知识与来源分离思路，继续使用本项目归档及人工维护的hierarchy.json作为事实和关系来源；未复制外部LLM Wiki代码，无新增运行依赖。
