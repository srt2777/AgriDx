# 已有知识库图谱工作台

入口：`/#/knowledge?view=graph`。从统一知识目录选择“知识图谱”。

图谱由现有 `/api/knowledge/catalog` 的品牌、型号/系列、组件、零件层级生成，不新建第二份事实正文、不调用外部模型、不导入外部资料。默认收拢为一颗知识球。点击或放大后，整球平滑分成多个品牌球；进入品牌球展开该品牌的机型球，再逐层进入组件球、零部件球。球内微光表示下一层目录，层级面包屑或缩小可返回。点击零部件聚焦相应证据。侧栏展示原有知识卡、来源、页码及核验状态，可进入完整机型目录及诊断。没有零件或条目时保留缺口；未定位到零件的条目仍留在组件层级。

实线仅表示已经整理的目录关联，不表示因果、故障确诊、实车验证或完整覆盖。系列与待确认机型不等于具体型号；通识资料继续在独立浏览入口显示，不通过图谱自动提升证据等级。计数来自目录，不将跨组件引用相加当作新增条目。

球体支持拖拽惯性旋转、滚轮/按钮缩放、自动旋转、鼠标吸引/排斥力场、搜索定位和全景复位；球体聚焦时方向键旋转、Esc关闭详情，节点使用原生按钮支持Enter和空格。手机端证据面板放在球体下方，减少动态偏好关闭自动旋转、惯性与鼠标力场。资料读取有加载、失败重试与空状态。借鉴持久化知识与来源分离思路，继续使用本项目归档及人工维护的hierarchy.json作为事实和关系来源；未复制外部LLM Wiki代码，无新增运行依赖。


## 立体光照与空闲漫游（3.13.2）

用户选择浏览器WebGL路线，不接入UE5或Pixel Streaming。三维球面使用物理材质、方向光和轮廓光、真实遮挡、柔光后处理、球面纹理、星尘与环绕轨道。空闲4秒后默认缓慢环绕和轻微推拉；鼠标、触控或键盘操作会暂停漫游，停止后恢复。可随时关闭自动漫游；减少动态偏好会关闭漫游及连续光效变化。

WebGL场景按需加载，层级切换复用同一个渲染上下文。GPU不可用或上下文丢失时自动回到带明暗与光晕的兼容画面，目录节点、搜索、资料来源与证据浏览仍可使用。真实目录关系、知识正文、知识库版本和诊断逻辑不变。

## 边界粒子扩散（3.13.4）

用户要求把星系外观改成外围边界粒子密集、向外扩散。每颗知识球外表面新增一层粒子壳：粒子按斐波那契球面均匀铺在球面边界，越靠近边界越密，沿表面法线方向缓慢向外漂移，位移越大亮度越低并逐渐淡出，形成"边界致密、外部稀薄"的扩散光晕。

粒子扩散由顶点着色器按 `时间 × 每粒子速度 + 种子` 计算，相位在球面切线方向带轻微涡旋；亮度按视线夹角加权，只在轮廓附近保持高亮，避免颗粒糊在球面正中央。CPU 不逐帧更新位置，层级切换继续复用同一渲染上下文。中心球粒子数 3000，其余球 1200，均为加法混合并参与现有泛光后处理。减少动态偏好下粒子停在固定相位，只保留静态的边界颗粒层。

GPU 不可用或上下文丢失时的兼容画面同步增加对应粒子层（中心球 150 个、其他球 70 个、按同一密度曲线淡出），并随当前视角旋转；目录结构、计数、证据与诊断逻辑不变。
