# 故障检测演示工作台

入口：`/#/fault-detection`；园区中央车辆预览和智能诊断展区保留原入口并增加演示入口。

数据全为确定性模拟序列，以场景相对秒计时，不连接实车、不执行车辆控制、不配置真实维修阈值。温度场景在 +45s 触发预设事件；断流场景 +60s 后只保留 +59s 历史值，当前状态未知。播放默认暂停、后台自动暂停；支持重播与时间轴键盘定位。

复用 `PartsTractorScene` 和柴油模型，选中散热器仅表示关联结构，不表示确诊损坏。模型不是 LX2620 精确孪生，T70 不加载柴油遥测。WebGL 不可用时沿用静态结构降级，检查与曲线仍可使用。

资料经现有 catalog API 查询 `KB-LX2620-005`，校验来源、品牌、型号。原文、页码、适用范围和核验状态直接读取，未取得时保留无资料状态，不生成维修建议。该条目仅为温度场景的美国版 LX2620/LX2620SU 手册示例，其他场景不据此下维修结论。

演示笔记只存在本标签页 `sessionStorage` 的 `agridx-fault-demo-records-v1`，不调用设备记忆写入接口。记录保留场景与相对时间，回放早于记录时显示“记录时间在当前定位之后”。清除只删除演示笔记。未保存草稿和播放期间阻止自动刷新。聊天交接只预填带模拟标识、有长度限制的草稿，不自动发送。

本批只发布开发站。Tencent production 工作流支持主干合并提交消息含 `[dev-only]` 时跳过自动生产发布；本批 PR 合并提交使用此标记。该标记不改变其他提交的现有部署策略，不改服务器、DNS、密钥或仓库权限。

人工验收：三个场景、告警选中后模型/曲线/原文/检查联动、暂停重播、记录恢复与清除、缺资料、手机布局、键盘和减少动画模式。真实数据接入属于后续任务。
