# 拖拉机资料审阅队列

[pending.jsonl](pending.jsonl) 列出待核编号、品牌、型号、标题、原件定位与同品牌同标题主线编号。标题相同仍须比对机型、版本和技术正文。编号不同也可能是同一知识。

[sources.jsonl](sources.jsonl) 记录对应的 213 个来源、原件地址和哈希比对。此次重新计算本地 PDF 哈希并与登记值相符的来源有 101 个。网页结果沿用早先下载复核的回执。空值表示该项尚待核实。候选进入维修检索前还需逐条核实正文、适用范围、重复内容、检索及来源。待核数不计入新增或正式发布门槛。
