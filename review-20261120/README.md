# 拖拉机资料审阅队列
对照 [GitHub 主线提交](https://github.com/srt2777/AgriDx/commit/032b5d5ff371df0e3c35ccec4570a23aa22f0dfa) 的 9,832 条归档，逐个检查累计审阅包的 2,354 个唯一编号。其中 1,241 个编号已在主线，另有 1,113 个编号待核。累计审阅包之间有重叠。

[pending.jsonl](pending.jsonl) 列出待核编号、品牌、型号、标题、原件定位与同品牌同标题主线编号。标题相同仍须比对机型、版本和技术正文。编号不同也可能是同一知识。

[sources.jsonl](sources.jsonl) 记录对应的 213 个来源、原件地址和哈希比对。此次重新计算本地 PDF 哈希并与登记值相符的来源有 101 个。网页结果沿用早先下载复核的回执。空值表示该项尚待核实。候选进入维修检索前还需逐条核实正文、适用范围、重复内容、检索及来源。待核数不计入新增或正式发布门槛。

[其他手册批次的待审正文](scoped-manual-candidates.jsonl) 以 [PR #312 的提交](https://github.com/srt2777/AgriDx/commit/f3a347220e4628e8f15ac7e5530158684a9890d5) 为对照，保存了 404 条不同编号的候选卡片、出处、机型与原文位置。其中 49 条来自 7M-2304、7M-2504 的中国版手册，适用于整机序列号 100001 起且实装总成匹配的车辆。此清单与其他审阅包可能交叉，尚未纳入发布统计。

[4.1.50 主线统计](main-4.1.50-counts.json)以任务起始提交为基线，按唯一编号和条目分类计数。原有两个队列合计 1,517 个主线外编号。逐页复核 7M 手册时，发现其中两个编号对应同一次双滤芯保养，已合并候选正文并保留原编号供追溯。[49 条的核验记录](deere-7m-source-check.json)

另从同一手册的清洁保养章节核出 [8 条新候选](deere-7m-cleaning-candidates.jsonl)，涉及冷却器复位、进气滤芯、燃油系统排水及 DEF 维护。共覆盖主线外的 1,525 个不同编号；其中 1 个已标记并入另一个候选。技术内容的跨来源去重及 Agent 验证仍在进行。
