# 司稼 ESP32-S3 实机修复工程（验收中）

适用：ESP32-S3 N16R8、ILI9341 320×240 + XPT2046、INMP441。此目录是 2026-11-11/12 实机修复批次，尚未作为正式 RV 版本发布。固件内部版本暂为 0.1.1，不代表传感器闭环方案 RV0.1.1 已实现。

## 当前功能

- 监测：网站 SSE 模拟数据，水温/油压/转速可选，60 秒横轴、按指标收紧纵轴；终端叠加变化和间歇故障并明确显示“模拟增强”。没有接入真实农机传感器。
- 对话：按住屏幕按钮录音，松开后 STT → 带历史的诊断接口；“常用”提供六条问题/追问。语音耗时仍待实测，网站后端尚未同步部署。
- 联网：扫描、选择 Wi-Fi 并输入密码。网络凭据存设备 NVS，不放入仓库。
- BOOT 短按切页，长按约 1 秒校准；页面禁止水平滑动，回复保留纵向滚动。校准保存问题仍在诊断，不能认为断电保存已修复。
- 开机“耕知·耘诊 / 司稼 AgriDx”动画、导航指示动画、60 秒空闲拖拉机漫游；流畅度待实机验收。

## 目录

- `src/`、`include/`：固件源码、字体、硬件配置。
- `tools/`：字体生成/解码校验、TFT 驱动补丁、遥测主机测试。
- `docs/REPAIR-20261111.md`：本批过程与验证记录，后面的更正覆盖前面尝试。
- `docs/LEGACY-RV010-README.md`：历史说明，非本批操作依据。
- `release/`：构建产物及 SHA-256/验证状态清单；不包含 NVS 或整机备份。

## 构建与有线升级

复制 `include/secrets.h.example` 为 `include/secrets.h`，按需本地配置；不要提交后者。

```sh
pio run -e esp32-s3-n16r8
python3 tools/check_fonts.py
```

已有本项目兼容 16MB 分区表的设备，仅更新应用并保留配置：

```sh
esptool --chip esp32s3 --port <串口> --baud 921600 write-flash 0x10000 .pio/build/esp32-s3-n16r8/firmware.bin
```

不要整片擦除，不要把应用文件写到 0x0。新板首次烧录须核对 bootloader/partition，与应用分区升级分开处理。当前只验收 USB 更新；无线升级暂缓。

## 验证边界

16ms LVGL 定时器不等于 60FPS；SPI 显示当前 40MHz，未宣称 80MHz 稳定。此批只验证 S3，历史 C3 配置未经本次回归。完整字体和遥测协议测试不替代实际触摸、语音时延、动画和校准持久化验收。GitHub 保存与正式网站部署分别记录。
