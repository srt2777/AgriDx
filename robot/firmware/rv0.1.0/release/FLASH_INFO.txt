# 构建环境：PlatformIO 6.2.0 / espressif32 8.0.0 / Arduino core 3.3.12
# 库：LVGL 9.6.0、TFT_eSPI 2.5.43、ArduinoJson 7.4.3、XPT2046_Touchscreen（GitHub 直链 f956c5d）
# 板子：ESP32-S3-N16R8（16MB Flash + 8MB PSRAM），分区 default_16MB.csv
#   app0 0x10000 大小 0x640000（6.5MB）；固件 1,945,360 字节，余量充足。

重要：这批 .bin 是用占位配网编译的（secrets.h 里是“你的WiFi名称”）。
烧进去能上电、能滑动、能看界面，但连不上 WiFi，问答和监控都走不通。
要联网使用：按 docs/FLASHING.md 把 include/secrets.h.example 复制为
include/secrets.h、填入真实 WiFi 名称密码，重新 pio run，再按下面命令烧录。

## 烧录命令（任选一种）
# 四文件分开烧（与 pio run -t upload 完全一致）：
esptool.py --chip esp32s3 -p /dev/ttyUSB0 -b 460800 write_flash \
  0x0 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 firmware.bin
# 或合并镜像一次烧完：
esptool.py --chip esp32s3 -p /dev/ttyUSB0 -b 460800 write_flash \
  0x0 sijia-rv0.1.0-merged-16MB.bin
# 或直接用 PlatformIO（会重新编译并上传）：
#   pio run -t upload
# Windows 下串口一般是 COM3/COM4 之类，把 /dev/ttyUSB0 换掉；macOS 是 /dev/cu.usbserial-*。

## 首启检查（详见 docs/FLASHING.md）
1. 串口 115200 看启动日志，确认 WiFi 已连接、拿到 IP。
2. 首页三屏左右滑动流畅，圆点指示跟着走。
3. 对话页问一个问题，约 15–20 秒出答案（失败会自动重试 1 次）。
4. 监控页三块表盘有数，5 分钟趋势图在走；数据是正式站仿真，界面已标“模拟数据”。
