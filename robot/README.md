# 司稼小机器人（Robot）

把司稼智能体装进单片机小机器人：单片机 + 触摸屏做交互终端，智能体仍跑在正式站（https://agridx.xyz）上，机器人通过 WiFi 调正式站接口。

目标：第十二届全国大学生智能农业装备创新大赛 A 类（自由选题），实物原型。报名截止 2026-11-30，作品提交 2026-12-01–12-20。

## 架构（一句话）

单片机不跑智能体本身，只做交互终端；司稼智能体仍跑在正式站上；机器人通过 WiFi 调正式站的诊断接口（`POST /api/chat`）和遥测接口（`GET /api/telemetry/*`），屏幕上问答和监控。

已验证（2026-11-09 实测）：不带 Origin 请求头的 `POST https://agridx.xyz/api/chat` 返回 HTTP 200，约 18 秒出答案。单片机裸 HTTP 客户端默认不带 Origin，正好符合服务器的同源检查。

## 版本

机器人版本独立编号，前缀 RV（Robot Version），与 AgriDx 项目版本（4.x）和界面版本（NV/OV）互不干扰。每个版本一个方案文件，发布后冻结，改动进新版本。规则见 [VERSIONS.md](VERSIONS.md)。

| 版本 | 状态 | 内容 |
|---|---|---|
| [RV0.1.0](versions/v0.1.0.md) | 进行中 | 问答终端 + 监控页面；硬件已下单（ESP32-S3-N16R8 + 3.2 寸触摸屏 + 语音硬件 + 18650 电源） |
| [RV0.1.1](versions/v0.1.1.md) | 进行中 | 传感器闭环：多节点分布式传感，普通拖拉机数字化实时监测 |
| [RV0.2.0](versions/v0.2.0.md) | 规划 | 语音交互（STT 提问 + TTS 播报），硬件已买 |
| [RV1.0.0](versions/v1.0.0.md) | 规划 | 传感器闭环合入的完整版（指导书 v1.0） |

## 目录

- `VERSIONS.md` — 版本规则与版本表
- `versions/` — 各版本方案（每版一个文件）
- `firmware/` — 固件工程（Arduino + LVGL），随版本落地后放入
