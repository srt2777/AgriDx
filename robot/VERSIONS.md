# 机器人版本规则（VERSIONS）

## 编号

机器人版本独立编号，前缀 RV（Robot Version），语义化三段：`RV主版本.次版本.修订号`，例如 RV0.1.0。

- 与 AgriDx 项目版本（4.x）互不干扰：机器人分区的新增与改动不升项目版本（2026-11-06 版本规则：单个 PR 不带项目版本号升版）。
- 与界面版本（NV/OV）互不干扰：机器人屏幕界面是原生 LVGL 界面，不是网页新版/旧版。

## 递进规则

| 递进 | 含义 |
|---|---|
| 修订号（0.1.0 → 0.1.1） | 同范围修补：接线修正、文案调整、Bug 修复，不加能力 |
| 次版本（0.1.0 → 0.2.0） | 新能力：语音交互、移动底盘等整块新增 |
| 主版本（0.x → 1.0.0） | 参赛定版里程碑：整机联调通过、可完整演示 |

## 文件规则

- 每个版本一个方案文件：`robot/versions/v<主>.<次>.<修订>.md`，发布后冻结，不再原地改。
- 改动进新版本：修补发修订版，新能力发次版本。
- `robot/README.md` 的版本表是唯一总表，新版本发布时同步更新。
- 固件代码随版本放入 `robot/firmware/`，文件名或子目录注明对应 RV 版本。
