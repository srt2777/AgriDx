# 司稼小机器人 RV0.2.0（规划）：语音交互

> 状态：规划。硬件已买（RV0.1.0 实购清单里已有 INMP441 麦克风 + MAX98357A 功放），软件排在 RV0.1.0 问答联调之后，不堵主线。

## 目标

在 RV0.1.0 问答终端的基础上加语音：按住说话提问，答案语音播报。演示时评委可以直接对着机器人说话。

## 硬件（已买，无需新增）

| 件 | 型号 | 接线 |
|---|---|---|
| 麦克风 | INMP441（I2S 数字麦） | SCK → BCLK、WS、SD → DIN；3.3V 供电 |
| 功放 | MAX98357A（I2S 功放） | BCLK、LRC/WS、DIN；5V 供电；输出接小喇叭（4Ω 3W，需另买） |

麦克风与功放可共用 BCLK/WS，DIN/DOUT 分开。

## 软件

- 录音：INMP441 采 16kHz 单声道，端上做 VAD（静音检测）切句。
- 识别（STT）：先走云端 STT（手机端或云端服务），不堵主线；端侧离线识别以后再看。
- 合成（TTS）：答案文本走云端 TTS 生成音频流，MAX98357A 播报；播报时屏幕同步滚动显示文本。
- 交互：播报中点屏幕可打断；超时无声自动回首页。

## 验收

- 安静环境下说“拖拉机发动机启动困难怎么办”，识别正确并出声回答。
- 播报与屏幕文本一致；打断后不卡死。

## 不做

- 不做离线语音识别（RV0.2.0 不排）。
- 不改 RV0.1.0 已定的硬件与问答链路。
