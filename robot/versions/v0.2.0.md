## 目标

在 RV0.1.0 问答终端的基础上加语音：按住说话提问，答案语音播报。演示时评委可以直接对着机器人说话。

## 硬件（已买，无需新增；喇叭未到货）

| 件 | 型号 | 接线 |
|---|---|---|
| 麦克风 | INMP441（I2S 数字麦） | SCK → BCLK GPIO 17、WS → GPIO 18、SD → DIN GPIO 19（默认）或 38（后备）；3.3V 供电 |
| 功放 | MAX98357A（I2S 功放） | BCLK GPIO 17、LRC/WS GPIO 18、DIN → DOUT GPIO 20（默认）或 47（后备）；5V 供电；输出接小喇叭（4Ω 3W，需另买，**仍未到货**） |

麦克风与功放共用 BCLK/WS，DIN/DOUT 分开。⚠ GPIO 19/20 是 S3 原生 USB
D−/D+：板子到货后先确认 Type-C 是原生 USB 还是桥接芯片，再决定用默认脚
还是后备脚 38/47（见 `robot/firmware/rv0.1.0/docs/ASSEMBLY.md` §4.2）。

## 软件链路（已实现）

```
INMP441 录音（16kHz 单声道，固件 voiceTask，core 0）
  → POST /api/voice/ask（raw audio/wav 体，44 字节 WAV 头 + PCM，不带 Origin）
  → 服务端 STT（faster-whisper，默认 tiny）识别提问
  → 复用 /api/chat 诊断服务（stateless，无 sessionId、无记忆）
  → Edge-TTS 云希男声 zh-CN-YunxiNeural 合成 16kHz 单声道 WAV
  → /ask 返回小 JSON {question, transcript, answer, audioUrl, ...}
  → 固件 GET /api/voice/audio/:id 流式下载进 PSRAM
  → MAX98357A 播报（I2S，软件增益 0.85）
```

- 录音最长 15 秒（到时自动停并发送），短于 0.5 秒视为误触丢弃；
  播报音频最长 60 秒，超长拒收、只显示文字。
- `/ask` 回答**念出来的部分只取前 600 字**（实测约 600 字答案合成约 45 秒
  音频；1200 字会超 60 秒播报上限导致整段播不了）；文字答案仍全文显示在
  屏幕上，`audioTextTruncated=true` 时照实标。
- 音频不走 base64：`/ask` 只给 `audioUrl`，WAV 存在服务端内存（5 分钟
  TTL、上限 20 条，过期 GET 到 404）；固件 base64 分支留着当回落。
- TTS 失败时 `/ask` 仍返回 200 + 文字答案（`audioUrl: null`），固件只显示
  文字，不编假音频。
- 交互：播报中点对话屏可打断；BOOT 长按 ≥800ms 开始录音、松开发送，
  播报中按一下 BOOT 打断；语音问答与文字问答互斥。
- 语音限流 10 次/分钟/IP（独立于 chat/telemetry）。
- C3 两个环境不编译语音代码、不增加体积（`SIJIA_VOICE_ENABLED=0`，
  `build_src_filter` 排除 `voice.cpp`）。

## 验收

- 安静环境下说“拖拉机发动机启动困难怎么办”，识别正确并出声回答。
- 播报与屏幕文本一致；打断后不卡死。
