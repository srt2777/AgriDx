# 故障诊断与维修方向：正文研究知识

本批 7 条知识条目、2 篇来源，规范数据保存在 `shared/research-knowledge.json`，供 Node、静态预览和 Agent 共用，不重复建立另一份内容。

- 文献归档：现有 486,764 条 Crossref 元数据通过 `literatureArchiveEntry` 统一映射为稳定 CR 编号、书目正文、引用和来源哈希。采用读取时映射，保留既有分片，不复制半百万文件，不增加统计条数。
- 研究知识：RK 编号条目来自出版商 HTML 正文的指定章节，保留中文归纳、短原文定位片段、片段 SHA-256、论文 DOI、工况与局限。读取过相关全文章节不等于下载了原始 PDF，也不等于专家核验或独立复现。片段哈希只能检查该片段是否变化，不能替代语义核验。
- 手册与通识：原有 13,236 条索引沿用原检索体系与来源规则。本批 7 条研究知识单列，不当作 7 篇文献；页面总索引为 500,007（原 500,000 条＋7 条研究知识）。
- 中国农机化学报不纳入本批或后续归档；原采集名单无该刊，归档转换同时拒绝已知中英文刊名。

## 使用

知识页每条文献提供“让 Agent 引用此文献”，进入聊天后由用户发送草稿。

- `查文献：tractor` / `查文献：拖拉机` / `查文献：10.1006/jaer.1993.1001`
- `查研究知识：液压` / `查知识条目：RK-GEAR-002`

这些请求走同一聊天服务的本地来源引用路径，不调用 LLM 编造摘要。元数据查询最多列 5 条、单次读取预算 10 秒，取消/失败不返回虚构来源。普通维修问题仍走原诊断路径；研究摘录不会通过此入口变成拆卸、调压等操作许可。

Agent 只读注册表增加 `search_literature`（宿主注入存储）和 `search_research_knowledge`，`get_knowledge_entry` 支持 RK 编号；Node 和静态开发预览均可读取。后台影子工具循环的结果依旧不替代用户可见诊断。
