# Branson 3620 / 4820 / 5520 原厂维修手册选页

- 来源编号：SRC-BRANSON-3620-4820-5520-B20W-202009
- 型号：3620 / 4820 / 5520
- 版本：B20W-202009，2020 年 9 月英文版

## KB-BRANSON-3620-4820-5520-B20W-202009-001｜通电后起动机小齿轮不推出

- 手册事实：先核对蓄电池供电和电缆压降，留意低温、电缆松动或腐蚀。核对线缆连接时按原厂断电流程。内部检查涉及电枢轴花键、磁力开关柱塞、线圈、钥匙回路和电刷。
- 适用限制：限本册所列 3620 / 4820 / 5520 和对应市场。
- 证据：SRC-BRANSON-3620-4820-5520-B20W-202009；PDF物理第70页；印刷第2-14页；发动机缺陷诊断与管理。

## KB-BRANSON-3620-4820-5520-B20W-202009-002｜小齿轮已啮合飞轮齿圈而起动机不转

- 手册事实：检查蓄电池电量，两段相接电缆以及电磁开关和电机的端子紧固状态。原表还列出齿轮啮合和起动机本体问题。
- 适用限制：限本册所列 3620 / 4820 / 5520 和对应市场。
- 证据：SRC-BRANSON-3620-4820-5520-B20W-202009；PDF物理第70页；印刷第2-14页；发动机缺陷诊断与管理。

## KB-BRANSON-3620-4820-5520-B20W-202009-003｜起动机转动而驱动齿轮无法啮合

- 手册事实：按原厂图核对安装位置、磁力开关柱塞调整和齿轮套弹簧。由维修人员断电后检查装配。
- 适用限制：限本册所列 3620 / 4820 / 5520 和对应市场。
- 证据：SRC-BRANSON-3620-4820-5520-B20W-202009；PDF物理第70页；印刷第2-14页；发动机缺陷诊断与管理。

## KB-BRANSON-3620-4820-5520-B20W-202009-004｜起动机和小齿轮动作但发动机不转

- 手册事实：原表的两个排查方向是起动机单向离合器和发动机内部。先确认小齿轮确已与齿圈啮合，再交维修人员区分。
- 适用限制：限本册所列 3620 / 4820 / 5520 和对应市场。
- 证据：SRC-BRANSON-3620-4820-5520-B20W-202009；PDF物理第70页；印刷第2-14页；发动机缺陷诊断与管理。

## KB-BRANSON-3620-4820-5520-B20W-202009-005｜发动机点火后很快熄火

- 手册事实：该行列供油管堵塞或滤芯受污染、燃油管进气、油箱盖通气孔堵塞。结合停机发生时间和故障前供油状况逐项确认。
- 适用限制：限本册所列 3620 / 4820 / 5520 和对应市场。
- 证据：SRC-BRANSON-3620-4820-5520-B20W-202009；PDF物理第71页；印刷第2-15页；发动机缺陷诊断与管理。

## KB-BRANSON-3620-4820-5520-B20W-202009-006｜油门回怠速后转速不稳

- 手册事实：按原表核对加速杆和拉线的调节状态，然后由维修人员排查进气到喷油泵、喷油器、喷油正时与泵本体。
- 适用限制：限本册所列 3620 / 4820 / 5520 和对应市场。
- 证据：SRC-BRANSON-3620-4820-5520-B20W-202009；PDF物理第71页；印刷第2-15页；发动机缺陷诊断与管理。

## KB-BRANSON-3620-4820-5520-B20W-202009-007｜寒冷条件下发动机输出下降

- 手册事实：书中把燃油管冻结或燃油析蜡列为低功率的一个分支，水分混入燃油另列一项。确认燃料和环境条件后按手册在安全场所恢复供油。
- 适用限制：限本册所列 3620 / 4820 / 5520 和对应市场。
- 证据：SRC-BRANSON-3620-4820-5520-B20W-202009；PDF物理第71页；印刷第2-15页；发动机缺陷诊断与管理。

## KB-BRANSON-3620-4820-5520-B20W-202009-008｜燃油消耗升高且怀疑回油管受限

- 手册事实：外漏之外，本版列出回油软管扭曲、压扁、堵塞，以及异常喷油量、喷油正时和压缩压力。先记录可见管路状态，交维修人员检查内部燃油回路。
- 适用限制：限本册所列 3620 / 4820 / 5520 和对应市场。
- 证据：SRC-BRANSON-3620-4820-5520-B20W-202009；PDF物理第73页；印刷第2-17页；发动机缺陷诊断与管理。

## KB-BRANSON-3620-4820-5520-B20W-202009-009｜发动机机油消耗升高且外部无明显漏油

- 手册事实：维修表区分气缸活塞间隙或活塞环问题、通风堵塞和加注过量，以及气门杆和导管间隙、气门杆油封或缸垫缺陷。后者需按本册测量确定。
- 适用限制：限本册所列 3620 / 4820 / 5520 和对应市场。
- 证据：SRC-BRANSON-3620-4820-5520-B20W-202009；PDF物理第73页；印刷第2-17页；发动机缺陷诊断与管理。

## KB-BRANSON-3620-4820-5520-B20W-202009-012｜传动油到液压齿轮泵前的两级过滤

- 手册事实：油液先通过吸油管接口前的滤网，再经过传动箱与齿轮泵之间的滤芯。排查供油不足时区分这两处部件，并按本册确认实际油路。
- 适用限制：限本册所列 3620 / 4820 / 5520 和对应市场。
- 证据：SRC-BRANSON-3620-4820-5520-B20W-202009；PDF物理第349页；印刷第6-53页；液压滤芯及滤网。

- 手册事实：该维修手册列首次使用满 50 小时更换液压滤芯，此后每 300 小时更换。现场须对照本版规定的液压回路与滤芯。
