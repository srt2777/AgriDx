## KB-MH-SYNC10-20261017-001｜Mahindra四驱驾驶室版涡轮增压器异响的分支检查与送修

- 原表将进气或排气系统受阻/泄漏列为候选，对应检查并纠正相应系统，不是听到异响就换增压器。
- 排气歧管出现来自发动机的异物、压气轮/扩压叶片积垢、增压器轴承异常、异物损伤压气机或涡轮、供油不足以及压气轮/涡轮叶轮损坏均标星号，应由Mahindra经销商处理。
- 整理边界：本表没有提供拆解、叶轮间隙、供油压力或转速参数；不得据异响自行确定坏件或拆解旋转部件。
- 证据：SRC-MH-6065-6075-CAB-REV01；Trouble Shooting / TURBOCHARGER / Turbocharger Noisy；PDF第114页／印刷第113页。仅选页核对，未全书审校、厂家复核或实车验证。

## KB-MH-SYNC10-20261017-002｜Mahindra四驱驾驶室版压气机或涡轮密封处漏油的候选方向

- 原表分别列压气机进气管受阻、排气歧管异物、排气系统受阻、增压器回油管受阻；对应检查并纠正，其中前两项还带经销商星号，不能省去送修边界。
- 涡轮增压器轴承壳油泥/结焦、压气轮或扩压叶片积垢、增压器轴承异常均要求联系Mahindra经销商。密封处见油不直接等于密封本身损坏。
- 整理边界：不补造拆装密封、清焦方法、油压或回油尺寸；原表的进气与排气原因必须按实车分别确认。
- 证据：SRC-MH-6065-6075-CAB-REV01；Trouble Shooting / TURBOCHARGER / Oil Leak From Compressor Seal / Turbine Seal；PDF第114页／印刷第113页。仅选页核对，未全书审校、厂家复核或实车验证。

## KB-MH-SYNC10-20261017-003｜Mahindra四驱驾驶室版液压不提升或提升缓慢

- 油量少/无油时检查并补至正确液位；吸油滤清器堵塞时清洁，损坏则更换；滤网堵塞时清洁或更换滤网。原表将滤清器与滤网分列，不能互换部件。
- 液压泵效率丧失对应由维修人员确认后更换泵；控制阀或控制连杆异常标星号，送Mahindra经销商。
- 系统超载时减载；液压油过冷时使油温回升。每项是不同候选分支，不是所有机器都要换泵。
- 整理边界：没有本机油品、加注量、压力和提升负荷参数，不据本条补造；检修前隔离能量并可靠支承机具，不能进入未支承机具下方。
- 证据：SRC-MH-6065-6075-CAB-REV01；Trouble Shooting / HYDRAULICS / No Lifting Or Slow Lifting；PDF第114页／印刷第113页。仅选页核对，未全书审校、厂家复核或实车验证。

## KB-MH-SYNC10-20261017-004｜Mahindra四驱驾驶室版未操作手柄而液压提升臂自行升起

- 原表将控制阀/连杆异常列为此特定现象的候选，处理栏是经销商星号，即联系Mahindra经销商检查，而不是给出自行调阀步骤。
- 整理边界：将此项与“不能提升”和“提升缓慢”分开；不要以试调手柄、旁路控制或在机具下观察来确诊，先停止相关作业并使机具得到可靠支承。
- 证据：SRC-MH-6065-6075-CAB-REV01；Trouble Shooting / HYDRAULICS / Hydraulic Lift Arms Lifting Without Lever Operation；PDF第114页／印刷第113页。仅选页核对，未全书审校、厂家复核或实车验证。

## KB-MH-SYNC10-20261017-005｜Mahindra四驱驾驶室版液压系统过热的进气与进水分支

- 本页液压系统过热条目列两个候选：系统进气对应查找空气进入处并密封；系统进水对应排出原油并重新加注。
- 整理边界：这是原表列出的两个方向，不证明排除了其他可能；不凭过热现象确定有水，也不提供未核对的油品、冲洗流程、工作温度或加注量。泄压、油液处理与检修由具备条件的人员按本机完整手册实施。
- 证据：SRC-MH-6065-6075-CAB-REV01；Trouble Shooting / HYDRAULICS / System Overheating；PDF第114页／印刷第113页。仅选页核对，未全书审校、厂家复核或实车验证。

## KB-MH-SYNC10-20261017-006｜Mahindra四驱驾驶室版制动不保持、拖滞与不释放须分开处理

- 制动不保持/打滑：原表为调整制动，必要时更换摩擦衬片；衬片浸油时检查最终传动小齿轮轴油封（原文bull pinion shaft oil seal），并保留经销商星号。
- 制动拖滞或不均匀对应调整制动；回位弹簧断裂对应更换；制动不释放则检查手制动是否已释放，以及制动轴是否卡滞。不能把四种现象配成同一个确定原因。
- 整理边界：制动异常先停止行驶并防止溜车；原表无本机调整量、间隙或拆装工艺，不能据此上路试车或盲目调节。
- 证据：SRC-MH-6065-6075-CAB-REV01；Trouble Shooting / BRAKES；PDF第115页／印刷第114页。仅选页核对，未全书审校、厂家复核或实车验证。

## KB-MH-SYNC10-20261017-007｜Mahindra四驱驾驶室版换挡困难、脱挡与传动异响的区别

- 换挡困难：使用正确黏度润滑油，并保留经销商星号。拨叉/操纵杆异常：原表为更换并联系经销商，不能只凭难挂挡即确定拨叉坏。
- 齿轮脱离啮合、传动零件损伤、换挡时异响均标星号，应由Mahindra经销商检查；传动系统过大噪声另列检查油位、使用正确黏度润滑油，并保留送修星号。
- 整理边界：以上现象分别核对，不补造齿轮、拨叉尺寸、润滑油牌号或拆箱流程；不能以行驶中反复强行换挡作验证。
- 证据：SRC-MH-6065-6075-CAB-REV01；Trouble Shooting / TRANSMISSION；PDF第115页／印刷第114页。仅选页核对，未全书审校、厂家复核或实车验证。

## KB-MH-SYNC10-20261017-008｜Mahindra四驱驾驶室版不充电与运行中充电指示灯亮的区别

- 蓄电池不充电：连接松动/腐蚀对应清洁紧固；蓄电池硫化/老化对应检查电解液液位与比重；风扇皮带松动/异常对应调整张力或更换；发动机转速过低对应提高转速；交流发电机异常标星号，应联系经销商。
- 发动机运行时充电指示灯亮是另一个原表分组：蓄电池异常对应液位/比重检查，发电机异常由Mahindra经销商检查，皮带松动/异常对应调整或更换。
- 整理边界：指示灯亮不直接证明电池坏；未核对电池结构时，不对密封免维护电池提出开盖加液/测比重。皮带及电路检查须先安全停机隔离，不能带转接触，也不补造电压或张紧参数。
- 证据：SRC-MH-6065-6075-CAB-REV01；Trouble Shooting / ELECTRICALS / Battery Does Not Charge；Charging System Indicator Glows With Engine Running；PDF第115页／印刷第114页。仅选页核对，未全书审校、厂家复核或实车验证。

## KB-MH-SYNC10-20261017-009｜Mahindra四驱驾驶室版起动机不工作与转动缓慢的分支

- 起动机不工作：连接松动/腐蚀对应清洁并紧固；蓄电池输出低对应检查电解液液位与比重；换挡杆处于挡位时回到空挡；PTO已接合时断开PTO。
- 起动机转动缓慢：蓄电池输出低对应同类电池检查；曲轴箱机油过稠对应正确黏度机油；连接松动/腐蚀对应清洁紧固。不能把“不转”和“转得慢”当一个现象。
- 整理边界：电池检查仅在结构允许且人员具备防护条件时进行，密封免维护电池不得据此开盖；不补造机油牌号，不短接起动机或旁路空挡/PTO联锁。
- 证据：SRC-MH-6065-6075-CAB-REV01；Trouble Shooting / ELECTRICALS / Starter Inoperative；Starter Cranks Slowly；PDF第115页／印刷第114页。仅选页核对，未全书审校、厂家复核或实车验证。

## KB-MH-SYNC10-20261017-010｜Mahindra四驱驾驶室版灯光不亮与灯光暗的分支

- 灯光不亮：保险丝熔断对应更换保险丝；线路松动或接法不当对应检查各连接是否清洁且紧固。需先确认故障分支，不盲目换蓄电池。
- 灯光暗：原表列为蓄电池充电、紧固电缆端子、检查灯具和清洁接点；这是与不亮分开的处理方向。
- 整理边界：更换保险丝前查清异常原因，并使用本机规定规格；本页没有额定电流，不补造数值，严禁加大规格或用导线代替。电气检查先隔离电源。
- 证据：SRC-MH-6065-6075-CAB-REV01；Trouble Shooting / ELECTRICALS / No Lights（含Lights burn dim行）；PDF第115页／印刷第114页。仅选页核对，未全书审校、厂家复核或实车验证。
