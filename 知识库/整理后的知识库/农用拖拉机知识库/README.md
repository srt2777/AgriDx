## 条目与证据规则

1. 每条用`## 条目编号｜标题`独立成段；JSONL的`entry_id`、`source_id`和`knowledge_path`必须对应。仅列入索引的正文段参与归档检索；README、待补清单、采集记录与原始文件不作诊断正文。
2. 先匹配品牌、完整型号、排放/动力、出厂配置、市场与手册版本；不匹配时返回资料不足。资料索引和背景报道不能成为具体维修步骤。
3. PDF物理页从封面按1计数，印刷页码按实际页脚核对；目录标引不一致时引用正文实际页。网页保留原网址、章节及快照哈希。
4. 故障表中的可能原因不等于确诊；记录现象、检查结果与反证，不能根据单一症状直接换件。油品、容量、压力、扭矩、接线和故障码不跨机型补齐。
5. 扫描页仅在目视核对后形成概述；未核对正文保留待核实。原件用词、版次或字段冲突不擅自修正。培训资料里的条件性参数以匹配本机随车手册为准。
6. 辅助导航与整机无人驾驶分别标记；配套系统手册不能代替无人拖拉机的急停、失联、避障或电池安全资料。

本批已完成索引和原件完整性核对，未完成厂家复核、全书审校、实车验证或诊断准确率评测。网站加载状态应以对应代码版本及启动后的`/api/health`为准，更新条目后需重新加载服务。
