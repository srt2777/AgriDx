# 首页加载与二级页面跳转 · 3.1.1

2026-10-12（上海）。用户反馈新版首页、二级页面切换以及直接输入域名打开都慢。本轮先修复可以在代码和浏览器中复现的前端等待，同时核对腾讯 CDN 响应；线上域名问题仍需服务器本机与外部域名对比，不能用本地页面变快代替线上验收。

## 已确认的前端问题与改动

- 公共 CSS 通过 `@import` 加载 Google Fonts，访问字体服务慢时会阻塞初始渲染。移除外部字体 CSS，使用 Apple、Windows 等系统安装字体；新旧页面不再请求 Google 字体。
- 路由共用最外层 `Suspense`，页面代码未到达时缺少稳定的导航和内容反馈。改为每个页面独立加载边界，并在切页时重置内容边界，导航仍可用于主题切换或转到其他功能。
- 模型工坊仅为读取 GLB URL 就静态引入模型模块，将约 1 MB 的三维代码带进页面加载链。把 URL 和类型移到轻量模块，查看器改为动态加载；预热模型页面不会加载渲染器或 GLB。
- 三维区域在进入可见范围后，先让页面绘制两帧，再在空闲时机打开场景。主动漫游、展区导览等操作提高优先级；离开页面时取消尚未开始的工作。保留原有园区、模型及操作，没有把三维展示删掉。
- 指针进入或键盘聚焦入口时预热相应页面，新版首页延后预热知识与诊断。节省流量及慢速 2G 连接不进行可选预热，明确点击仍可进入页面。
- 静止、暂停和固定视角的拖拉机查看器按需绘制，暂停时不继续惯性续绘；选中组件、展开和相机变化主动请求绘制。取消不用的环境贴图着色器预编译，离开时释放环境场景和完整渲染目标；WebGL 支持探测后释放临时上下文。
- 首页与知识页重复读取相同目录。本轮在当前标签页内复用已验证响应，5 分钟后过期，最多保留 32 组完整筛选条件；查询参数排序不影响命中，品牌、型号、组件、零件分别隔离。失败和取消不缓存，手动重试清除当前选择；刷新页面会重新读取。URL 筛选发生变化时立即隔离旧结果，不显示上一型号的证据。
- 知识页与空诊断页会提前引入约 158 KB（gzip 约 48 KB）的 Markdown/GFM 解析代码。改为共享动态模块，资料折叠时不挂载正文；展开或显示已保存/新答复时再加载解析器，等待期间显示原始文本，保留来源、适用范围、提问预填及 GFM 格式。

## 域名与腾讯 CDN

公开 DNS 查询显示：

```text
agridx.xyz → agridx.xyz.cdn.dnsv1.com → 13kd6ev2.slt.sched.intlscdn.com
```

本环境对首页与 `/api/health` 的多次 HTTPS 请求收到 HTTP 514、空响应，并带 `x-nws-log-uuid`、`x-cache-lookup: Return Directly`。这证明这里没有拿到正常页面或健康数据，不能直接认定服务器本机慢，也不能确认用户所在地区返回相同结果。未更改 DNS、CDN、Nginx、证书或运行密钥。

此前已请求维护者回传现有服务版本、本机 API / HTTPS 与域名首页 / API 的状态码和响应耗时、CPU / 内存以及 Nginx 压缩指令，多行命令没有反应后曾改为 8 秒超时的单行本机 API 检查。用户随后明确现在无法登录服务器，要求先改源码，因此本轮不再依赖服务器检查推进前端优化。恢复登录后，再按本机与域名对比结果核对源站、CDN 回源和静态资源压缩。若传输未启用 JS / CSS 压缩，三维代码本身的传输成本仍需服务器或 CDN 侧处理。
